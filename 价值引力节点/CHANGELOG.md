# 价值引力节点版本记录

本项目使用 Git 提交追踪修改，使用 `价值引力节点/v主版本.次版本.修订版本` 标签标记正式版本。后续版本追加记录，保留历史记录和已发布标签。

## v1.2.1 — 2026-10-26

- 将点击时的碎片缓存创建拆成按帧执行的小批次，准备期间继续运行宇宙动画，并提前准备主页合成层。
- 移除裂开前垫着完整背景的停留阶段；从第一帧使用连续外散曲线，让位移、旋转及缩放同步变化。
- 汇聚纹理直接读取主页的 `--paper` 实际底色，完全替换旧宇宙纹理；提前开始退去暖色，避免独立蓝色调造成的切换色差。
- 同一云端浏览器对比中，点击事件同步处理耗时约 43.3ms → 0.4ms；异步准备仍需时间，具体流畅度依赖设备。
- 验证：桌面与手机完整转场、重播、Escape 在准备阶段取消、窗口变化后正确完成、减少动态效果与键盘回归均通过，无 JavaScript 运行错误。

## v1.2.0 — 2026-10-26

- 移除 v1.1.0 新增的入口环绕线，保留点击中央星体进入主页。
- 宇宙背景改为连续纹理绘制与缓慢镜头漂移，移除每帧数百次三角形裁切及原有 24/30fps 限速，随浏览器刷新绘制。
- 爆炸碎片预先缓存局部纹理，减少重复裁切；减少火花数量，预先计算运动方向。
- 统一飞散和回收的端点位置、旋转与大小，消除阶段交接的跳变。
- 重组碎片由暖橙色逐渐转成主页深蓝灰色，主页同步淡入；移除反复生成的 SVG 页面遮罩，并在转场结束前淡去背景覆盖层。
- 同一云端无头浏览器的绘制函数耗时对比：背景平均约 1.76ms → 0.07ms，转场平均约 3.45ms → 1.07ms。该测量用于比较绘制开销，不代表所有用户设备的实际帧率。
- 验证：1440px 桌面与 390px 手机（2 倍像素比）的完整转场、重播、跳过及无横向溢出通过；键盘、减少动态效果回归检查通过，无 JavaScript 运行错误。
- 云端浏览器策略禁止 file:// 访问，直接本地文件打开未能在此环境复验；HTTP 方式验证通过。外部资源网络限制仍在。

## v1.1.0 — 2026-10-26

- 精简宇宙开场屏，仅显示“万物的开始，是每一次真实的相互环绕”。
- 移除开场副标题、角标、英文提示和文字按钮；用中央星体与缓慢环绕的细轨道承载入口，悬停与键盘聚焦时增强光感。
- 保留点击星体进入正文及重播；支持 Enter / Space 操作入口，Escape 跳过开场或转场，并尊重减少动态效果设置。
- 验证：桌面点击进入正文、重播、Escape 跳过、手机宽度 390px 无横向溢出、减少动态效果下键盘进入均通过；无 JavaScript 运行错误。
- 外部字体、图标和 Tailwind 的网络访问限制仍沿用 v1.0.0 的已知限制。
